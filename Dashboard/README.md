# S.G.R.S: Sistema de Gestión en Redes y Seguridad

Primera versión navegable del centro de monitoreo. Está construida con HTML, CSS y JavaScript sin dependencias externas.

## Ejecutar

Haz doble clic en `iniciar_dashboard.bat` (o ejecuta `python -m http.server 3000`). Se abrirá automáticamente `http://localhost:3000` en tu navegador.

## Incluye

- Resumen de salud y ruta de señal.
- Métricas de dispositivos, IPs, ancho de banda y alertas.
- Inventario buscable, filtrable y ordenable.
- Bitácora de altas, bajas y cambios.
- Capacidad IPv4 por segmento.
- Navegación móvil, diálogo accesible y notificaciones.
